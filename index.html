DEV LOG

v1.9.6
Pop out is back and is required on the Google Apps Script version (Google's frame blocks mouse lock). If your browser blocks the pop-up you can still play in the frame without mouse lock. In other frames, such as the Claude artifact, Pop out is optional.

v1.9.5
The game can now be hosted as a normal web page (where browsers allow real mouse lock) and still use your Google Sheet leaderboard, initials and admin panel through the Apps Script web app URL.

v1.9.4
Removed the Pop out button.

v1.9.3
Mouse lock rebuilt: asks only inside clicks and key presses, uses raw input, retries with a plain request, re-locks on any click or key, filters mouse spikes, and never gives up once a lock has worked. Esc no longer toggles pause twice.

v1.9.2
Mouse lock hardened: raw input where supported and re-lock on any click. Where the browser blocks mouse lock (Google Apps Script or claude.ai frames) the game switches to stick mode: the cursor's offset from the centre turns the camera, so it never runs out of screen.

v1.9.1
Mantling is less forgiving: a mantle now takes 0.72 s (0.3 s longer than before).

v1.9 · Oct 15, 2026
Mantling takes longer (0.42 s) with a longer cooldown. All saved times, ghosts and records were reset. Dev log added. Admin panel can clear every board at once.

v1.8
Grappling gun reworked: tighter aim (about 10°), 36 m range, walls block the rope, 2.2 s hold, 0.9 s cooldown. Tracks 4-7 rebuilt around it (Skyhook teaches it, Gauntlet, Updraft and Overclock build on it). Grapple removed from the race, Endless, arena and mazes.

v1.7
Arcade initials for leaderboards. Hidden admin panel with password and emailed code, bans, audit log, notices. Google Sheets leaderboard for the Apps Script version.

v1.6
Touch controls for phones, controller menu navigation, checkpoints between race sections, mouse cursor hidden while playing, mouse-lock hint.

v1.5
Grand Circuit obstacle race against 3 AI racers: 10 random sections out of 50, boost pads, shortcuts. Meta Breakout: 20 fixed mazes plus Random, 22 shoppers, sync and ID-code skill checks, practice from any stage.

v1.4
Mantling added. Medal times tightened by about 10%.

v1.3
Full UI overhaul, gamepad support, rebindable keys, Track 3 (Slipstream), ghost and particle colours unlocked by gold medals, surface footsteps and ambient audio.

v1.2
Practice Arena, Endless mode, Track 2 (Hyperline), shared leaderboards.

v1.0
Launch: Track 1 (Neon Overdrive), momentum movement with sprint, slide, wall run, air dash, ghost racing and local records.
